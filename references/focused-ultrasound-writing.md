# 用于聚焦超声综述的调用指南

适用于 `review-reconstruction 0.3.5-development`。先由你确定专题、读者和文稿类型，再用方法包组织选文、证据综合、章节、图表及正文；已有案例的医学结论和检索截止不自动适用于新题。

## 准备与调用

将完整方法包放在目标项目的 `.agents/skills/review-reconstruction/`，确认该目录直接包含 `SKILL.md`，并保留 `references/`、`assets/`、`scripts/` 等配套目录。在该项目中开启新任务，可明确写“使用 `$review-reconstruction`”；若新技能未出现，重启Codex后再检查。位置与显式调用方式见[OpenAI技能文档](https://learn.chatgpt.com/docs/build-skills)。连接GitHub只提供仓库访问，不会自动安装项目技能。

也可在能读取本地文件的环境中直接指定：“请读取 `[方法包的绝对路径]/SKILL.md`，按需加载其引用文件，执行下述任务。”这样可明确调用依据；其他宿主能否自动发现技能，须以实际环境为准。

本版已在Codex CLI / app-server的项目环境实测技能发现、A模式重构、B模式写作和单句润色对照。观察范围为入口、配套文件读取及响应；没有新增医学写作效果评分，旧版测试分数不转授本版。

以下请求中的方括号替换为你的实际信息。材料可以是本地目录、索引、已有稿件或可访问的来源入口。

## Mode B：为新问题写综述

```text
使用 $review-reconstruction 的Mode B。
专题：[已选定的聚焦超声问题]；目标读者：[读者]；体裁：[叙述综述/系统综述/其他]；核心问题与新增价值：[内容]；检索时间窗及截止：[日期]；纳排范围：[条件]。
从现有材料[路径或入口]和最新进度继续，按已明确的问题开展或更新检索。判断来源各自增加什么信息，形成候选取舍、研究家族和主张—证据对应，再组织证据组、章节及过渡。实际查看重要原图表，将模型、比较、终点、时间和影响适用性的限制写入相应判断。
交付：[约定篇幅与语言]的正文、来源定位、原创可编辑比较表/示意图及图注。将编辑取舍与科学正文分开。缺少关键材料时说明影响，继续不依赖该材料的部分；可分阶段保存，保持约定总范围，不自行改成少数论文试点。
```

## Mode A：重构已有综述

```text
使用 $review-reconstruction 的Mode A。
对象：[母综述及补充材料]；读者与体裁：[信息]；历史窗口：[作者声明或待核]；来源：[现有全文库、引用索引、既有分析和进度]；目标范围：[指定章节或完整综述]。
先恢复作者实际的问题、分类、选文、综合判断和转场，再独立评价证据支持范围。共享文献复用已核内容，分别分析各处引用职责；核对母综述图表，并追溯关键面板。历史候选检索先固定问题与日期，不由未引用推定作者排除。
交付：有页段依据的案例、证据组—段落—章节实例、中英文科学改写及原创可编辑图表与图注。区分直接观察、分析推断与未知；保留缺源、部分阅读、版本及图像缺口，说明其对结论的影响。
```

持续复用有效记录，避免重复下载和分析；同一研究的后续报告按新增信息分工，不重复计为独立验证。阅读与重构不要求重新实施原研究。每阶段保存实际完成范围和接续位置，最终以可使用的正文与图表交付，阅读数量和规则数量仅用于追溯。
