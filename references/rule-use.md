# 按写作问题调用规则

先说清当前需要作出的判断，再读取能改变这个判断的规则。63条记录是十案产生的候选方法，以下八组是查用入口，不是新增八条经验证的通则。原规则的来源、反例和失效条件继续保留在[candidate-rules.csv](candidate-rules.csv)；完整归组见[rule-routing.csv](rule-routing.csv)。

## 从当前问题进入

| 当前写作问题 | 先读取什么 | 需要得到的产物 | 到哪里停止外推 |
|---|---|---|---|
| D1：范围和章节为什么这样分？ | T05-RUL01确定操作性范围；按读者任务选择T01-RUL01、T02-RUL01或T08-RULE01；跨模型时补T03-RUL01 | 有纳入目的和证据角色的范围陈述、入口问题—出口判断章节卡 | 分类可以交叉；一个成熟分支不能替其余分支提供证据 |
| D2：某项证据当时可用吗，更新究竟改变了什么？ | T09-RULE04核日期；T10-RULE04核引用用途；T04-RUL02比较判断；定义与覆盖不一致时用T06-RUL06 | 日期与版本依据、按问题记录的取舍、旧判断—新增证据—新判断对照 | 公开不等于作者获得；未引不等明确排除；新纳入不等新发表 |
| D3：这些表、报告和更正究竟属于谁？ | T10-RULE01建研究—报告映射；冲突时T10-RULE05/06；按需要补登记、制剂或跨页表连接规则 | 一个可复用的身份／版本记录，关联受影响的具体主张 | 标题相似不能自动合并；已关联更正不等其他数字全部正确 |
| D4：这句话比原研究多说了什么？ | T04-RUL01把谓语对齐测量；合引句用T09-RULE08；按缺口选择监测、预测、机制或代理终点扩展 | 分句—测量—来源—未测连接表及受限改写 | 不能用未测的中间连接把观察、机制、决策和患者结局串成已证实因果链 |
| D5：这些结果能放在一起比较吗？ | T09-RULE01锁定比较对象；T10-RULE03锁定估计量；再按终点、长期随访、绝对获益或实际分组选择扩展 | 保留对象、设计、终点、时点和估计方式的证据组；明确的综合判断 | 不可比就分层说明，不强算统一效应；当前分析不能直接继承母试验的因果标签 |
| D6：安全结论为什么不同？ | T06-RUL02分开事件属性；T07-RULE01比较暴露、测量与时点；T08-RULE04约束因果解释 | 事件表和条件化冲突综合，指出哪种差异已有依据、哪种仍未知 | 关键条件缺失时不能归因；短期未见事件不等普遍安全，发生事件也不自动证明归因 |
| D7：图表让读者看到了什么，又暗示了什么？ | T09-RULE13判定图的证据类型；拼图用T02-RUL03或T08-RULE05；再核编码、单位、范围及阶段 | 回答具体问题的原创可编辑图表、图注和逐面板来源 | 图形邻接、同色或连续箭头不会创造独立重复、共同量纲、个体轨迹或临床因果关系 |
| D8：问题需要专门的方法检查吗？ | 筛查用T10-RULE02；诊断阈值与验证用T10-RULE-DIAGNOSTIC-TRANSFER；经济模型用T09-RULE14 | 与该问题相称的路径、诊断证据表或模型条件说明 | 不把专门模块强加给不涉及该问题的普通综述 |

这不是固定的八步流程。重构整篇综述可以从D1、D2进入；修改一段比较结论可以直接从D5进入，再补确有必要的身份或图像检查。数据不足时记录具体受影响的判断，继续可以完成的部分，不以填满全部模板作为开始写作的门槛。

## 重叠规则怎样共用工作

| 有共同部分的规则 | 共用一次的工作 | 保留不同规则的理由 |
|---|---|---|
| T01-RUL02、T04-RUL01、T09-RULE02 | 同一主张—测量映射 | 前者检查跨环节链条，中者约束具体谓语，后者检查代理与患者结局的连接；只在这些问题出现时追加对应判断 |
| T02-RUL04、T10-RULE06 | 同一原报告—更正—日期记录 | 机制解释的边界变化与数值／图例的版本纠正是不同影响；不各建一套重复书目 |
| T06-RUL04、T10-RULE01 | 同一study_id/report_id映射 | T06还要求解释并发治疗时序，不能仅靠报告去重解决归因 |
| T04-RUL03、T06-RUL01、T10-RULE03 | 同一单位与分母字典 | 检索计数、技术成功定义和重复事件／生存估计不能互相替代 |
| T02-RUL03、T08-RULE05、T09-RULE13 | 同一逐面板来源表 | 来源身份、验证阶段和观测／模拟类别是三个检查维度，可写在同一行而不合成一种等级 |
| T06-RUL02、T07-RULE01、T08-RULE04 | 同一事件与条件表 | 事件定义、跨研究可比性和因果归属各有不同的证据要求 |
| T05-RUL01、T06-RUL06、T10-RULE04 | 同一范围与角色记录 | 术语范围、实际章节覆盖及按关键问题的证据纳入可能不同；不可据一个定义句替代全文或纳排记录 |

本次保留63个ID。相似的规则不构成63次独立支持，也不要求执行63套检查；共享来源、共享过程和不同适用条件必须同时可见。来源数量多不能替代反例分析或新题验证。归组是本项目的方法整理（I），不是作者公开的决策流程。

## 把核查落到正文

选择一条拟写入综述的中心判断，先确认它对应的读者问题及来源，再只打开必要的规则行。完成核查后，修改实际产物：选文理由、证据组、章节出口、段落、图注或表达强度。不要以新增审计表代替用户要的正文。

例如，一段文字把成像读数增加写成治疗增强，先用D4区分读数和效应；如果证据是同一记录处理前后的比较，用T08-RULE02限定解释。如果配图又把体模定位和未来控制概念放在同一层，用D7检查面板。最终产物是一段说明“测量校正改变估计，而本组资料未比较治疗结局”的综合及相应图注；不因此推断整个领域没有控制研究。具体来源与改写见[本版更正](corrections-v033.md)。

四组[证据到成文实例](cross-case-methods.md)第四节展示这些入口如何共用：经骨聚焦用D1/D2/D5决定沿革与工程比较的篇幅；病理和行为用D1/D4/D5区分背景、核心比较与可写谓语；组织监测用D4/D5/D6/D7连接组织参照、不同性能任务和图表；经皮递送用D3/D4/D5/D6/D7识别复用数据的增量、条件与恢复证据。输出是实际改过的段落、章节卡或比较表，不是额外四套规则。D8仅在筛查、诊断或经济问题确有需要时加入。

完成后检查：正文是否仍与来源的版本、对象、终点和时点相符；重要限制是否写在它影响的判断旁；关键未知是否具体；中英文是否表达相同的证据边界。其余完整工作流及段落范例见[从问题到综述正文](method-decisions.md)。

本入口尚未经过新题独立对照。它降低重复读取和重复建表的预期作用需要实际运行观察，不能由文件检查或本页自述认定有效。
