# 工作流

需要具体案例、完整段落与章节衔接时，配合[从问题到综述正文](method-decisions.md)使用；下述步骤用于组织工作，不是成品正文必须出现的标题。

## Mode A

先恢复原文，再评价。以作者明确范围为D、依据结构推得的读者任务为I、作者未公开的筛选经历为U。真实的过程记录优先于推测；没有日志时不伪造PRISMA排除表。

完整关系表与阅读内容表用途不同。关系表保留母文位置、编号和修辞角色；阅读内容表以稳定文献ID复用设计、结果与局限；study_id在证实同一研究后才连接。书章或同文件多报告使用PDF起始页定位，不以文件数替代文献数。

同期候选策略先写明问题、同义词、数据库、时间情景和资格标准，再执行和比对。题名限制会漏掉正文涉及主题的研究；排序有限的检索不是全库召回。记录技术过滤失效及修正，不能偷偷删除越界记录后宣称历史过滤正确。声学／物理／工程主题应补相应学术来源，临床资料优先官方来源与原刊。

对每一重要主张输出三个层次：作者怎样综合（页段与引文）；证据实际支持范围（设计、比较、终点、时间、偏倚）；自己的评价／改写（有依据的推断及边界）。共同引文在不同综述中的任务要分别处理。

图表先实看，再记录问题、形式、阅读顺序、比较维度、来源、正文和图注分工。示意图不赋予未报告时间；机制箭头区分必要、充分、参与与假说；数据图保留单位、分母、不确定性。图例与正文相反时先查更正，不能只按直觉修图。

## Mode B

把“写一篇综述”转成明确的问题和读者决策。叙述性综述可以提供概念综合；系统综述必须有相应可复核方法；范围综述侧重证据版图。方法选择先于套用报告清单。

在同一主张下并列支持、限制、冲突和缺失证据。原始研究数量多不必然更强；设计、人群、干预组合、终点或随访不同，先解释可比性。不为获得整齐结论擅自合并不可比数据或新做meta分析。

提纲每节写成要解决的问题，指定需要的证据和可达结论。正文段落通常从判断开始，再给必要证据与差异，最后交代对下一问题的影响；实际结构按读者和材料决定，不固定段数或句式。

图表服务需要并行比较、跨层级连接或时间变化的问题。先定数据来源和不应暗示的关系，再选形式；交付原创可编辑成品与图注。语言改写基于新的论证表达，不模仿作者声线或拼接原句。

## Ultrasound extension

仅当结论依赖声学暴露时加载：从原文准确记录频率、压力／强度定义、脉冲、占空比、时长、焦域、传播路径、温度测量、空化／微泡、靶组织与反馈。此模块用于解释已发表证据的条件，不补造未报告参数，不把设备名或“低强度／非热”当作机制证明，也不生成未要求的实验优化方案。对其他医学主题不强加这些字段。

## 规则与评价

每条规则保留触发、输入、步骤、输出、案例页段、支持、反例或未找到反例、适用与失效条件。来源仅一个案例时标明范围；规则类型分通用、体裁及领域扩展。

规则冻结后再运行未用于归纳的新题；先保存评分标准、资料包、允许工具与资源。普通指令和技能组使用一致材料与模型条件，评价证据准确性、历史一致性、选文理由、综合、衔接、边界、图表任务、语言和追溯。保存可核的错误例，不只总分；模型或代理评阅只能称有限验证／自评，不能冒充外部独立专家审阅。用于修订的测试不再是未见集。
