# 工作流

需要具体案例、完整段落与章节衔接时，配合[从问题到综述正文](method-decisions.md)使用；下述步骤用于组织工作，不是成品正文必须出现的标题。

## Mode A

先恢复原文，再评价。以作者明确范围为D、依据结构推得的读者任务为I、作者未公开的筛选经历为U。真实的过程记录优先于推测；没有日志时不伪造PRISMA排除表。

完整关系表与阅读内容表用途不同。关系表保留母文位置、编号和修辞角色；阅读内容表以稳定文献ID复用设计、结果与局限；study_id在证实同一研究后才连接。书章或同文件多报告使用PDF起始页定位，不以文件数替代文献数。

同期候选策略先写明问题、同义词、数据库、时间情景和资格标准，再执行和比对。题名限制会漏掉正文涉及主题的研究；排序有限的检索不是全库召回。记录技术过滤失效及修正，不能偷偷删除越界记录后宣称历史过滤正确。声学／物理／工程主题应补相应学术来源，临床资料优先官方来源与原刊。

对每一重要主张输出三个层次：作者怎样综合（页段与引文）；证据实际支持范围（设计、比较、终点、时间、偏倚）；自己的评价／改写（有依据的推断及边界）。共同引文在不同综述中的任务要分别处理。

图表先实看，再记录问题、形式、阅读顺序、比较维度、来源、正文和图注分工。示意图不赋予未报告时间；机制箭头区分必要、充分、参与与假说；数据图保留单位、分母、不确定性。图例与正文相反时先查更正，不能只按直觉修图。

## Mode B

把“写一篇综述”转成明确的问题和读者决策，写清范围、体裁、截止与相对已有综述的新增价值。叙述性综述可以提供概念综合；系统综述须有相应可复核方法；范围综述侧重证据版图。方法选择先于套用报告清单。

按问题保存候选查询、资格标准和实际结果，再建立证据组。沿用候选表或证据表，说明每份来源将支持、限制、补充独立重复、解释差异或提供哪项必要背景；不另建一套同义台账。来源适合在某段作背景，不等于它被科学排除；系统综述也不能因结果难以纳入叙事而改变预定资格。

在同一主张下对齐设计、人群、比较、终点和时间，再说明支持与分歧。对后续报告，先核它增加的是新对象、新测量、新时间点，还是对既有数据的再分析。按实际增量安排篇幅，不按论文数量投票，也不为获得整齐结论擅自合并不可比数据或新做meta分析。

用章节卡把证据组接到成文：入口是读者尚不能回答的问题，出口是这组证据足以成立的判断；下一节回应该判断留下的具体问题。核心比较展开必要的参照和差异，沿革或概念背景可简写并给出处；篇幅随本节任务而变。只有主题标签而无出口判断的提纲仍需收束。

正文表达科学判断及研究之间的关系，通常先给可成立的判断，再给必要证据、差异及其意义；实际结构按读者和材料决定，不固定段数或句式。教学注释另行解释为何选择这些来源、为什么压缩或展开，不能让“综述应该怎样写”混入可直接使用的科学正文。

需要并行查看的模型、终点、参照或时间交给原创可编辑图表；正文解释这些比较共同支持什么、在哪个分界处不能继续合并。先定图表要回答的问题，再选形式和图注，避免逐格复述表格。图表与正文应具有一致的比较对象、分母、来源和语言强度；具体的篇幅分配及成文示范见[跨案例方法](cross-case-methods.md)。

在当前证据允许的范围内形成可审阅的提纲、段落和必要图表，再围绕真正会改变判断的缺项定向核对。交付时保留已确定、部分确定与未知的内容及出处，不以继续补资料代替成文，也不把已完成的短篇综合称为全量范围完成。

定稿时直接检查已写出的判断：影响适用范围的已知限制，应进入首次范围句、受影响主张或表注，并核对中英文是否一致；留在内部记录中还不够。随后回看同一核心报告中是否有会限定该判断的其他相关测量。按它对读者问题的贡献决定是否保留，同时说明预设/事后性质、缺失与意义未决；不按P值筛选结果，也不要求罗列所有次要终点。这两步复用正文和原有证据表，不新建台账。它们来自0.3.4两题的局部评阅发现，属于后续开发改进，尚未在新的未见题上验证。

## Ultrasound extension

仅当结论依赖声学暴露时加载：从原文准确记录频率、压力／强度定义、脉冲、占空比、时长、焦域、传播路径、温度测量、空化／微泡、靶组织与反馈。此模块用于解释已发表证据的条件，不补造未报告参数，不把设备名或“低强度／非热”当作机制证明，也不生成未要求的实验优化方案。对其他医学主题不强加这些字段。

## 规则与评价

每条规则保留触发、输入、步骤、输出、案例页段、支持、反例或未找到反例、适用与失效条件。来源仅一个案例时标明范围；规则类型分通用、体裁及领域扩展。

规则冻结后再运行未用于归纳的新题；先保存评分标准、资料包、允许工具与资源。普通指令和技能组使用一致材料与模型条件，评价证据准确性、历史一致性、选文理由、综合、衔接、边界、图表任务、语言和追溯。保存可核的错误例，不只总分；模型或代理评阅只能称有限验证／自评，不能冒充外部独立专家审阅。用于修订的测试不再是未见集。
