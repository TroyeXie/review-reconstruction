# 0.3.2新题迁移验证方案

状态：方案已形成，尚未生成本轮对照输出或评分。先完成本地方法包核查并冻结文件清单，再按本方案锁定材料、任务及运行设置。旧0.3.0两题结果仍单独报告，不作为本版结果。

## 要检验什么

主要问题是：使用方法包是否改变选文理由、跨研究综合、章节判断和表达边界，而不是只让输出更长或表格更整齐。至少一题为聚焦超声相关医学任务，一题为非超声医学任务。每题普通指令与启用技能各运行一次；单次、少量任务只能产生有限证据，不据分数差宣称普遍有效、稳定性或统计等效。

暂定题域为：①聚焦超声用于子宫腺肌症的症状、生活质量与后续干预证据；②膝骨关节炎伴肥胖患者中减重治疗与疼痛／功能证据。二者是选材起点，尚未确认为未见材料。锁定前必须将DOI、PMID、登记号、报告版本及研究家族与十案语料、规则归纳材料、全部既往测试及其修订材料核对；高度重复的研究不作未见证据。若任一题缺少合适的新材料，先记录替换理由、固定新题和标准，再运行，不在看到输出后换题。

## 输入与对照

1. 每题从冻结的问题查询与时间窗口形成一个有界候选集合。按预先记录的相关性与可获得性标准选择可完成的题目规模，不为制造阳性、阴性或预期错误挑文献。保存原始命中、筛选和未获得材料；有界检索不称穷尽。
2. 给两个条件相同的候选书目、原始摘要、可用全文、关键原图及任务要求。材料保留来源和版本，但不附带本项目已经写出的结论、纠错答案、排除标签或“注意某陷阱”提示。完整原文只在本地评估中使用，不随公开技能包分发。
3. 普通条件使用明确、合理的写作要求；技能条件只额外获得冻结的方法包。两组都能查看相同原始材料和图像。精确模型／推理设置若可固定则固定，否则逐项记录可观察配置及不可核实部分，不能声称完全一致。
4. 每个条件使用独立的新上下文；不传入本项目历史、另一组输出、目标答案或评阅意见。工具权限、资源上限和输出要求相同。先锁定全部输入及文件哈希，再开始第一组运行。
5. 两组均交付候选取舍及理由、研究／报告对应、问题驱动的章节提纲、一组可追溯综合、一张原创可编辑证据表、600–1000汉字的中文综合正文和180–250词的独立英文综合。字数统计仅含对应正文，不含标题、表格、参考文献或过程说明；不通过事后补写消除原输出偏差。

该设置检验有界原始资料下的筛选和综合，不单独证明独立全库检索能力。若另做自由检索测试，需先单独固定相同数据库权限、时间窗、查询资源和评价办法，不能与本轮结果混算。

## 预先固定的九个评价维度

各维0–4分，等权，合计36分，同时保留逐项证据；总分不能掩盖严重事实失败。

| 维度 | 评阅时必须检查的可观察行为 |
|---|---|
| 证据准确性 | 人群、比较、设计、主要／次要终点、数值与方向符合原文；未提供的结果不补造 |
| 历史与版本 | 使用声明窗口内的实际版本；后续结果／更正分层；未由年份推定作者可获得性 |
| 选文理由 | 按问题说明纳入、背景、边界或排除作用；候选不按阳性结果投票；同研究多报告不当独立重复 |
| 综合 | 对齐可比维度；解释冲突或不可比之处；证据组形成明确判断而非摘要串联 |
| 结构与衔接 | 每节的入口、证据及出口一致；转场依据前一判断；不靠标题重命名掩盖证据错配 |
| 科学边界 | 测量、机制、技术、代理及患者结局分开；分母、观察窗、因果范围与未测事项可见 |
| 图表任务 | 可编辑表回答具体问题；来源、单位和比较条件完整；无伪造数值、因果箭头或无条件排名 |
| 科学语言 | 中英文表达独立且结论一致；限定词对应实际不确定性；不是拼贴或泛化免责声明 |
| 可追溯性 | 中心判断能回到具体报告、版本和页段／表图；空链接、错误编号和未知状态不冒充已核 |

统一等级锚点：0＝该维未完成或中心判断错误；1＝有零散正确处理但主要要求缺失；2＝部分完成，存在会影响读者判断的重要缺项；3＝主要判断正确可追溯，余下缺项不改变中心解释；4＝完成该维且能用实际证据处理关键边界、冲突或反例。4分不以篇幅长、表格多或语言流畅为依据。评阅者须逐维给输出定位和原始来源定位；不能只给印象分。

严重事实失败另列：编造来源或结果、研究身份或比较组错置、关键数字／效应方向错误、把实际未测终点写成获益、把未读资料称为已核、把同研究报告错误计为独立重复并据此改变综合。逐项说明影响，避免仅用扣总分替代解释。格式、字数和执行资源偏差单列，不自动伪装为医学事实错误。

## 运行、评阅与修订顺序

先冻结方法包，再锁定两题输入、资源设置和本评价方案。若条件允许，用新上下文代理分别产出，再将随机编码的输出与同样的原始材料交给独立评阅者，不提供组别映射或作者预期。保留代码映射，待评分完成后揭盲。文本特征仍可能使组别被猜出，因此只报告实际做到的隔离程度。

独立代理不可用时可以继续准备材料、核对身份或完成其他全量工作；不把同一上下文先后写两版当作公平独立对照。根代理自查可发现问题，但须标为自查，不能冒称独立评阅。宿主自动发现／激活另需真实运行观察；按路径加载、文件规范通过或代理说“会使用”均不能替代。

评阅后保留原输出、评分、失败位置及限制，再决定是否修订。任何用于修订的题目及近似研究家族退出下一轮未见集。若两组都表现很好，优先报告未显示增益及可能的任务上限；若技能组只是增加结构但未改善关键判断，应明确这一失败。只有完成实际运行和检查后，才将状态从“计划”改为“已运行”。
